西凤·终端通 — 终端360°全景数字化沙盘 移动端原型

项目概述

基于”白酒企业终端360°全景数字化沙盘”方案文档，为西凤酒设计实现的移动端H5交互原型。采用国风红×金×科技蓝三色系设计语言，模拟手机壳框架，完整呈现双角色端的核心业务流程。

已完成功能

🎯 双角色登录

  • 管理者端（大区经理）/ 业务员端独立入口
  • 体验账号：zhang.wei（管理者）/ li.ming（业务员）

📊 管理者端（5个核心模块）

模块 功能点
首页大盘 终端总量/活跃率/动销率/风险门店四维统计条；动销趋势折线图；分公司排行榜；消费者互动数据（扫码率/开瓶率/好评率）
地图终端 模拟GIS地图、多类型点位（高风险红/预警橙/正常绿）；点位弹窗详情；电子围栏开关；多维筛选（全部/风险/活跃/预警）；列表/地图切换
纵向穿透 分公司看板→经销商列表（第二层穿透）→终端详情（第三层）；分公司柱状图对比
风险预警 37条风险分级展示（高/中/低）；一键下达任务；一键忽略
任务管理 任务列表（待接收/进行中/已完成）；快速下达任务Sheet；新建任务Sheet

🏪 终端详情页（第三层穿透）

  • 门店画像（门头照/类型/信用评级/店主信息）
  • 核心KPI：库存余量/本月动销/拜访次数/扫码率
  • 进销存趋势图（6个月历史进货+动销Bar Chart）
  • 风险状态卡（根据风险等级动态渲染颜色）
  • 责任主体反向溯源（分公司→经销商→业务员→终端）
  • 近期拜访时间线
  • 消费者反馈（扫码参与率/开瓶率/评价均分/用户评论）

👨‍💼 业务员端（4个Tab）

Tab 功能点
工作台 签到打卡（动效）；今日任务列表（紧急标红）；今日拜访路线；本月业绩概览
拜访打卡 库存盘点计数器；陈列合格情况选择；备注填写；照片上传模拟；提交打卡
我的终端 管辖43家终端列表；风险状态分类；一键导航到终端详情
业绩报告 拜访完成率柱图；本月轨迹时间线

功能入口路径

数据模型

实体 核心字段
分公司 终端总量/活跃数/风险数/动销率/增长趋势/经销商数
经销商 负责人/门店数/活跃数/库存/风险终端数
终端 类型/级别/信用/库存/动销/拜访次数/扫码率/进货峰值/补货预测/责任主体
风险预警 终端/类型/等级(high/warning/info)/描述/时间/归属分支
任务 标题/类型/关联终端/指派人/截止日期/状态/优先级
业务员 今日路线/任务列表/管辖终端/打卡记录/月度业绩

技术栈

  • 纯静态 HTML5 + CSS3 + Vanilla JS（单页SPA架构）
  • Chart.js 4.4.0：动销趋势折线图、进销存柱状图、圆环图、分公司对比图、业务员拜访完成图
  • Google Fonts Noto Sans SC：中文字体
  • CSS自定义属性：品牌色系统（西凤红/国风金/科技蓝）
  • CSS动画：页面切换、风险红点脉冲、Sheet弹窗上滑
